# 🍕 FastAPI Pizzaria

API REST desenvolvida com Python e FastAPI para gerenciamento de pedidos de uma pizzaria delivery.

## Tecnologias

- Python
- FastAPI
- SQLAlchemy
- SQLite
- JWT Authentication
- Uvicorn

## 📌 Funcionalidades

- Cadastro de usuários
- Login com autenticação JWT
- Geração de access token
- Rotas protegidas
- Criação de pedidos
- Adição de itens ao pedido
- Cancelamento de pedidos
- Controle de usuários administradores
- Relacionamento entre tabelas com SQLAlchemy
